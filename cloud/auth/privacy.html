pdfpal cloud privacy

Google sign-in identifies the owner of an optional cloud library. Sign-in alone does not upload your documents. You choose to enable synchronization in the desktop app.

When enabled, library metadata and selected portable content are stored in your account's Firebase library. PDF uploads require configured file storage. AI-provider accounts remain separate and device-local. Diagnostics and usage analytics have separate controls and are off by default.

This sign-in page keeps credentials in memory and returns them to the requesting pdfpal app on this computer. It does not collect usage analytics.

During this testing release, retain local exports. Contact the application maintainer before relying on cloud storage for recovery or account erasure.
