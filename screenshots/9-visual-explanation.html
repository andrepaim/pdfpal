2. Let the sentence supply the clues

Illustrative example
Read the explanation

In self-attention, a query for one token is compared with keys from the other available tokens. Those learned scores become weights. River is a useful human-readable clue here; actual attention weights depend on the trained model, layer and head. This is not a measured attention map.

3. Mix the context into the word

Illustrative example
Read the explanation

Softmax turns query–key scores into nonnegative weights summing to one. The head uses these weights to sum value vectors. The result is a vector, not a dictionary definition or a hard choice between two pictures. Multiple heads, residual connections and other layers add further processing.

Takeaways

  • Context helps distinguish different uses of the same word.
  • Attention combines value vectors using learned weights.
  • This is an illustrative analogy, not a measured attention map.
